## About
A beginner-friendly Python Streamlit project demonstrating Gemini AI Lab.

## Run
1. Install Python 3.10 or newer.
2. Open this folder in VS Code.
3. Run `pip install -r requirements.txt`.
4. Copy `.env.example` to `.env` and replace the placeholder with your own API key.
5. Run `streamlit run app.py`.
6. Open the local URL shown in the terminal.

**Note:** API calls require internet, a valid API key, and any applicable quota or billing. Never upload `.env` to GitHub.
